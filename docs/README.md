## 命名规范

文件名 `[阶段]_prj标识_概要_YYYY-MM-DD.md`；跨目录引用加 `cross` 前缀；日期取文件头 `created` 字段；重命名文件 frontmatter 加 `alias: 旧名` 保旧链接可达。豁免：`README.md`、`agent.md`（AI 会话入口镜像）、非 Markdown 数据文件。仓库侧全文见 `D:\FPGA\AGENTS.md`「git 与文档规范」与 `D:\FPGA\docs\README.md`。

**文档类型（文件名首段）可选值**：阶段号（`阶段一` / `阶段二之N` / `阶段三` / `阶段二前置`）之外的「无阶段归属类型」共 8 种 —— `前置` · `参考` · `里程碑` · `汇报` · `规划` · `追踪` · `结论` · `架构` · **`导览`**。其中 **`导览` 为 2026-10-01 新增**：**已完成工作说明**——作为仓库 README 的**补充**（README 才是入门第一份文档），只展开「已完成的工作」的内容与实现路径；**不含操作指导与术语教学**，与「照着做」的操作文档、「看证据」的调试记录均不同类；仓库侧登记见 `D:\FPGA\docs\README.md` 命名规范表。

**存放规则（2026-10-01 起，两类分开放）**：

| 判据 | 放哪 | 典型文件名关键词 |
|---|---|---|
| **读它是为了"照着做"**（步骤/规格/判据设计/清单） | `操作文档/` | 实操单 · 实施单 · 开工草案 · 开工开发文档 · 前置清单 · 验证单 · 作战卡 · 演示文档 |
| **读它是为了"看结果/看证据"**（做完之后的记录与结论） | `调试记录/` | 调试记录 · 执行记录 · 测试报告 · 独立复核 · 断点核查 · 复现记录 |

混合型（既有改造说明又有自检证据）**以主导内容归类**：证据为主 → `调试记录/`，步骤为主 → `操作文档/`。
跨目录引用按新路径写（例：`[[调试记录/阶段三_prj10_W3轨A执行记录_2026-10-01]]`）；移动文件时**必须同步修正全库引用**（2026-10-01 拆分时已批量修正 28 处，残留 0）。
