# B3 执行单：数据面换层（AXI DMA）——含硬前置 B3-0（Lw/Lr 实测）

> **缺漏检查结论（2026-10-12，本单是对开工草案 B3 行的细化补全）**：
> ①草案 B3 只有表行 + 散落约束，无专属执行文档；②**"Lw/Lr 实测"与"DMA 换层"必须拆步**——结论文档定案 Lw/Lr 是 B3 硬前置（"排 B1 后、B3 前"），且它是纯增量 RTL（不依赖 DMA）；③GET_LATENCY 回读通路需**双路径**（UDP 0x05 + 软核 Lite 寄存器，B 版形态判据三源）；④延迟计数器落点在 ui_clk 域的 `axi4_master_bridge`，回读需经 frame_mem_if 的 2FF CDC 跨域——草案未提；⑤仲裁器 3 主扩展属 B3-1（换层时才需要），B3-0 不动。

## 〇、总体结构（三步走，每步独立可验证/可回退）

| 步 | 内容 | 判据 | 为什么拆 |
|---|---|---|---|
| **B3-0** 延迟可观测（纯增量） | 桥内 `lat_w/lat_r` 握手拍数计数器（方案甲）+ **双路回读**：UDP `GET_LATENCY(0x05)` + axi_lite_regs 读表扩两寄存器 | TB 正负对照 + 板上 N≥100 帧 min/中位/max 稳定分布（µs = 拍×3.332ns）；与粗上界 <11,300 拍、条件上界 ≤2100 拍做一致性核对（顺带判定其前提真伪） | 不依赖 DMA；Lw/Lr 是换层的设计输入（DMA 描述符深度/预取量）与 B4 速率归因的基线 |
| **B3-1** 桥②换层（EGRESS 读，MM2S） | `axi4_master_bridge`(②) → AXI DMA MM2S 512b；仲裁器扩 3 主；描述符由软核下发（源地址 = 槽号×槽距 + SLOT_BASE） | **四档逐字节 PASS**（数据零破坏——读路径失败不污染写入） | 先读后写：失败可恢复 |
| **B3-2** 桥①换层（INGRESS 写，S2MM） | 桥① → AXI DMA S2MM 512b；**写槽规则须与规则号 1 逐字等价**（Q2：写布局自由 ≠ 可丢地址信息） | 四档 + **10MB 100%+SHA + 双桥计数对账闭合**（口径同 J4） | 写路径动了数据布局，判据最重 |

## 一、B3-0 离线部分（本轮范围）实现要点

1. **计数器落点（`axi4_master_bridge.v`，ui_clk 域，~40 行）**：
   - `lat_w`：`awvalid&&awready`（最后一拍 AW 握手）→ 首个 `bvalid&&bready` 的拍差；**饱和计**（无响应不翻转，超时由既有 `stat_bresp_err`/W_DRAIN 兜底——不加新超时逻辑，避免吃时序余量）；
   - `lat_r`：`arvalid&&arready` → 首个 `rvalid&&rready` 的拍差；同样饱和计；
   - 输出 16 bit ×2（最近值）+ 可选累计/次数（首版只做最近值 + min/max，共 6×16b=96b——**ui 域加 96b 曾致 WNS −1.142**，故 min/max 放**回读侧 user 域软算**：计数器只在 ui 域存最近值，user 域读回时自己维护 min/max/分布——关键时序决策）。
2. **CDC**：frame_mem_if 现成 2FF 链模式新增一跳（ui→user，计数器值类慢变信号，2FF 足够）。
3. **回读双路**：
   - **UDP 路**：`cmd_channel` 加 `OP_GET_LATENCY = 8'h05`（0x05 空闲已核实）——回包 v16=lat_w、v16b=lat_r、v16c=lat 序号（PC 脚本轮询打印分布）；
   - **Lite 路**：`axi_lite_regs` 读寄存器表扩两行（如 0x20 LAT_W / 0x24 LAT_R，当前读表只用到 0x1C）——软核轮询、min/max 自算、串口打印（**B 版正式形态**；注意坑 #44：先读后打）。
4. **契约扩展**：W5 契约 §2.1 opcode 表补 `0x05` 行（应答 v16/v16b/v16c 语义）——改毕设契约文档 + 双 RTL 同步（cmd_channel 与 axi_lite_regs 各自的 localparam）。

## 二、判据与负向对照

**判据口径（2026-10-12 实测订正）**：`lat_w/lat_r` 量的是"桥观测延迟"（含桥自身流水/队列），
与 MIG 模型参数**非逐拍 1:1**（实测 AR_LAT 8→200 对应 lat_r 9→249）。故离线判据只保证
活性/确定性/响应性/不死锁，**绝对值只在板上取**（板端无模型参数可对照，数值即答案）：

| 项 | 判据 | 实测 |
|---|---|---|
| 活性 | 隔离帧后 `lat_w`/`lat_r` 非零 | 84 / 9 |
| 确定性 | 同配置连测 3 次读数完全相同 | 3/3 一致（四配置全通过）|
| 写侧响应 | W_DLY +5 → `lat_w` 精确 +5 | +5 ✓ |
| 读侧响应 | AR_LAT 8→200 → `lat_r` 显著单调上升 | 9 → 249 ✓ |
| 不死锁 | 四参数点 `bresp_err == 0` | 0 ✓ |
| 无副作用 | W2 回归 STAT 行与基线逐字一致 | ✓ |
| 板上分布 | N≥100 帧 min/中位/max 稳定（**B3-0 板上场次，最终验收**）| 待板 |

**已知局限**：W_DLY=12 点测得 70（< W_DLY=0 的 84，3 次重复一致=确定性行为），推测长 B 延迟下
桥写 FSM 已回 IDLE、武装/闭合配对形态改变；板上用 min/中位/max 分布判据可规避（详见
[[调试记录/阶段三_prj11_B3-0延迟可观测离线记录_2026-10-12]] §四）。

## 三、风险与回退

- **时序**：ui 域只加"最近值"两个 16b 寄存器 + 比较器（在回读 user 域）——比方案乙（96b ILA）轻一个量级；构建 WNS≥0 门限自动把关；若仍超，回退 = 只留 lat_w/lat_r 最近值、砍 min/max 维护。
- **回退**：B3-0 是纯增量（不触任何既有路径），出问题直接 revert 该 commit 即可，位流回退烧 `d14425f2`。
- **不影响 B1/B2 判据**：新计数器零副作用（不进任何 FSM 判决路径，只读观测）。
