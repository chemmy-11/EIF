## 5. iperf3（主目标）

```powershell
# 接收端（PC2）：iperf3 -s -p 5201 -4
# 发送端（本机）：先小流量
iperf3 -u -c 10.10.0.2 -p 5201 -b 10M -t 10 -4 --get-server-output
# 阶梯
foreach ($b in '50M','100M','200M','500M') {
  iperf3 -u -c 10.10.0.2 -p 5201 -b $b -t 10 -4 --get-server-output
}
```

- **吞吐口径 = 服务端接收速率**（`--get-server-output` 里的 receiver 段）
- 同步跑 `p13_pcap_audit.py` 做字节级审计
- **不得用客户端发送速率反推桥上界**
- 跑不通 → `NOT_TESTED` + 原因（v4 连接阶段超时要原样记录）
