## 3. 执行顺序

### 3.1 基线对照（两板都基线）

1. 两板烧 `C856BA83` + ELF；串口 `d` 进 DMA；`list_targets` 认板。
2. 3 帧探针：双向各 3 帧，`pk_frames`/`mem_wr_frm` 各 +3；记录起始/结束计数（16 位模 65536）。
3. 制造可控闪断（优先**拔插光纤 5–10 s**；记录起止时间；不要动其他线）。
4. 恢复后**不重烧**，等 30 s，发 3 帧；记录是否 `+3`、`mem_len_err/stall/hard/soft`、是否需要重烧。
5. 若卡死：按恢复阶梯尝试（`d` 翻转 → `rst -processor`+`dow`+`d` → PL 重配置），记录哪一种有效、耗时。
6. 恢复后重烧两板，确认基线可继续（为 B1 轮准备）。

### 3.2 B1 对照（两板都 B1）

1. 两板烧 `E9BE2B14` + `probes_b1.ltx` + ELF；`d` 进 DMA；3 帧探针 `+3`。
2. 同样闪断方式/时长；恢复后不重烧，最多等 **30 s**，发 3 帧；记录恢复时间与 `+3`。
3. 反向 B→A：重复闪断，检查 `up_frames/prev_wr/mem2_wr_frm/mem2_rd_frm` 恢复且帧完整。
4. 断电重烧：整板断电→上电→重烧→`d`→3 帧通；记录耗时。
5. 恢复阶梯逐项记录（哪些有效/无效）。

### 3.3 失败时的下一步

- B1 不恢复：先确认闪断确实发生（链路 `ch_up` 掉过、`ch_up_evt` 增加）、探针/lTX 配对正确、DMA 已进；再考虑 B1D 诊断；**不要直接判“补丁无效”**。
- 基线恢复/B1 不恢复，或反之：记录异常，按 `INCONCLUSIVE` 处理，不硬写结论。
- 任何“未重烧恢复”的结论必须有 `reset_recovery_log.csv` + ILA 前后快照，不接受口头。
